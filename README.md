# 📊 E-Sales Data Cleaning Project (SQL)

## 📌 Project Overview
This project focuses on **end-to-end data cleaning** of an **E-Sales transactional dataset** using SQL.  
The original dataset contained **1004 records** with several data quality issues such as missing values, duplicate records, inconsistent categorical values, negative quantities, invalid dates, and incorrect data types.

The objective is to transform raw data into a **clean, consistent, and analysis-ready dataset** suitable for reporting and business insights.

---

## 🗂️ Dataset Details
- **Dataset Type:** E-Sales Transactional Data  
- **Total Records:** 1004  
- **Tool Used:** SQL (MySQL)

---

## 🚩 Data Quality Issues Identified
- Duplicate transaction records  
- NULL values in multiple columns  
- Negative values in quantity  
- Inconsistent categorical values  
- Mixed and invalid date formats  
- Incorrect data types  
- Invalid email addresses  

## 🧠 SQL Concepts Used
- `SELECT`, `UPDATE`, `DELETE`,`GROUP BY`,`HAVING`,`ORDER BY`
- Subqueries and `JOIN`
- Window Functions (`ROW_NUMBER()`,`abs()`)
- Aggregate Functions (`AVG`, `COUNT`)
- Data Type Conversion Functions

---

## ✅ Final Outcome
After completing all data cleaning steps:
- Duplicate records were removed  
- Missing values were properly handled  
- Data types were standardized  
- Numerical and date values were corrected  
- Dataset became **clean, consistent, and analysis-ready**

---
## 📎 Conclusion
This project demonstrates practical SQL data cleaning techniques used in real-world scenarios and highlights the importance of data quality before performing any analysis.
